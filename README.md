# Puzzles App

A cross-platform mobile and web app for maths puzzles, similar to Strava but for puzzles.

## Features

- **Authentication**: Email/password, OAuth (Google, Apple), and guest mode
- **Home Feed**: View new puzzles and shared completions from followed users and channels
- **Puzzles**: Browse and solve puzzles from subscribed channels
- **Clusters**: Join private groups for schools/maths clubs
- **Profile**: View stats and manage your profile
- **Rooting**: Give kudos to posts (like Strava)
- **Admin**: Create and publish puzzles (admin-only)

## Tech Stack

- React Native + Expo
- TypeScript
- Expo Router for navigation
- Supabase for backend (auth, database, storage)
